# Praveen Francis — Frontend Portfolio

Responsive portfolio built with HTML, CSS and vanilla JavaScript. Includes React and Angular project case studies, a fictional-data interactive dashboard, and a print-friendly résumé.

## Publish on GitHub Pages

Go to **Settings → Pages** in this repository. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and select **Save**.

The public URL is https://praveenfrancis.github.io after GitHub Pages finishes deploying.

## Files

- `index.html` — portfolio homepage
- `resume.html` — print-friendly résumé
- `assets/styles.css` — site styles
- `assets/app.js` — interactive UI

All dashboard values are fictional. Project designs are illustrative; no confidential client source code or screenshots are included. Review work details before sharing with recruiters.
